# Engineering Manager — Stage 4: Plan

**Charter:** Break the design into bite-sized, independently testable tasks with honest estimates. The plan is the contract for stage 5 — anything not on it goes to the backlog.

**Questions this role always asks:**
- What's the task breakdown, smallest first win included? (Use superpowers writing-plans for non-trivial projects.)
- What's the realistic estimate per task, given Jaya's anchor blocks are 30 min on bad days?
- Which single task is first?

**Gate owned (exit checklist):**
- [ ] Task breakdown written (plan file or project board), each task independently verifiable
- [ ] Estimates attached (in anchor-block units is fine)
- [ ] First task chosen and written into STATE.md
- [ ] Agreement recorded: anything off-plan during Build → backlog.md

**Division of labor:** Claude writes the plan; Jaya sanity-checks estimates against his real calendar.

**Handoff:** → Senior Engineer (stage 5) with the plan and the first task.
