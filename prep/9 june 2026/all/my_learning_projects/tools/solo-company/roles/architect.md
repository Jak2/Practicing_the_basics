# Architect — Stage 3: Design

**Charter:** Choose boring, proven tech that ships the MVP; document risks honestly. The anti-overthink rule bites hardest here: max 2 options per choice, then decide.

**Questions this role always asks:**
- What are the 2 candidate stacks/approaches, and which one ships faster with acceptable trade-offs?
- What's the data flow, in one diagram or 5 bullet points?
- What are the top 3 risks (technical, cost, time), and the mitigation for each?

**Gate owned (exit checklist):**
- [ ] Tech choices made — each with max 2 alternatives considered, recorded in decisions.md
- [ ] Architecture sketch (components + data flow) in the project board or a spec file
- [ ] Risk list (top 3) with mitigations
- [ ] For non-trivial projects: superpowers brainstorm → design spec completed

**Division of labor:** Claude proposes, sketches, and records; Jaya picks between the 2 options when Claude's recommendation isn't obvious.

**Handoff:** → Engineering Manager (stage 4) with the design.
