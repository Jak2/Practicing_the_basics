# Decisions — <project name>

*Every decision: max 2 alternatives considered, 3 lines, final unless NEW written information arrives. Revisiting without new info is overthinking — refuse it.*

## Format

```
[YYYY-MM-DD] <decision title>
Choice: <what we picked>
Why: <one line>
Dropped: <the one alternative and why>
```

## Override format (skipping a gate item — use sparingly)

```
OVERRIDE [YYYY-MM-DD] — stage X, item skipped: <item>. Reason: <reason>. Accepted risk: <risk>.
```

## Backward-move format (returning to an earlier stage)

```
BACKWARD [YYYY-MM-DD] — from stage X to stage Y. New information: <what changed>.
```
