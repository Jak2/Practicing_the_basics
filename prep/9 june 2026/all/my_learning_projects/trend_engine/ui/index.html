📡 Trend Engine

Local dashboard — launch the daily pipeline and watch it work. Click any stage or step below to expand details.

Pipeline (click a stage to see what it does)

📥
Collect
Fetches raw signals from 4 sources in parallel-ish sequence:
  • Hacker News — top 60 stories
  • Reddit — hot posts from configured subreddits (via RSS)
  • YouTube — trending videos (US + IN), needs YOUTUBE_API_KEY
  • Wikipedia — yesterday's top pageviews
Any source that fails is skipped, not fatal. Toggle sources in config.py.
→
📐
Score
Pure math, no network/LLM calls:
  • Spike detection (z-score vs the topic's 7-day history, or same-day percentile if brand new)
  • Recency decay
  • Cross-source corroboration boost
  • Niche keyword weighting (AI/India ×1.5/×1.3)
  • Hard-excludes anything matching EXCLUDE_KEYWORDS
Produces the top ~150 ranked candidates.
→
🧠
Enrich
One Claude Haiku call on the top candidates:
  • Clusters/deduplicates same-story topics
  • Writes a one-line "why it's viral" explanation each
  • Tags category, platform fit, and trend stage
If ANTHROPIC_API_KEY is missing or the call fails (after 1 retry), the run falls back to degraded mode: math-only rankings, no explanations, empty platform briefs — but the run still completes successfully.
→
📄
Publish
Writes the final output to output/<today>/:
  • top100.html — the ranked report (open this first)
  • top100.json — same data, machine-readable
  • briefs/youtube.html, instagram.html, x.html — per-platform content angles
Also appends one row to output/run_log.md (shown below).

How to use this

1 Set your API keys (in a .env file)
Copy .env.example to .env in the trend_engine/ folder and fill in your keys — no need to export anything in your shell, the pipeline and this dashboard both load .env automatically. 
cp .env.example .env
# then edit .env and paste in your keys
Both keys are optional individually: without YOUTUBE_API_KEY that one collector just skips itself; without ANTHROPIC_API_KEY the whole run still completes, just in degraded (math-only) mode. The checklist above always shows current status.
2 Click "Launch Run"
The pipeline diagram above lights up amber on the stage currently running, green once it's done. Click any stage box any time to expand what it's actually doing — those panels stay static reference text, but the badge/color updates live.
3 Watch it work (~1–5 minutes)
The live log below streams raw output as it happens. Most of the time goes to Hacker News (60 sequential requests) and Reddit (paced to avoid rate limits). The status badge turns green on success, red on error — hover nothing needed, it's all on this page.
4 Open the report
Click "Open today's report →" once it appears (top right of the pipeline card) — that's your ranked Top-100 with explanations. The per-platform briefs (briefs/youtube.html etc.) are linked from inside that report too.
5 Tune what it searches
Edit trend_engine/config.py: SUBREDDITS, YOUTUBE_REGIONS, NICHE_*_KEYWORDS (boost scoring), EXCLUDE_KEYWORDS (hard filter), SOURCE_ENABLED (turn a whole collector on/off). No restart needed — just click Launch Run again.
6 Automate it (optional)
See README.md's "Running it automatically (cron)" section to have it run on a schedule without you clicking anything. It reuses the same .env file, so no extra setup beyond what you did in step 1.
