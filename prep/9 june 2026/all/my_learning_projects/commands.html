Ollama (Local LLM runtime)

Used by ContentPilot in local mode (llm.provider: ollama, model phi3:mini).

Core Commands

ollama run <model>Start and chat with a model.
ollama pull <model>Download a model from the registry.
ollama rm <model>Remove a downloaded model.
ollama listList all models installed on your computer.
ollama show <model>Display information and architecture for a model.
ollama cp <source> <target>Copy a model to create a new one.

Advanced Commands

ollama serveStart the background server manually.
ollama create <name> -f <path>Create a custom model from a Modelfile.
ollama push <model>Upload a model to the Ollama registry.
ollama psList the models currently loaded into memory.

In-Chat Slash Commands

Available inside an active ollama run session.

/byeExit the chat session.
/set <setting> <value>Change variables like temperature or system.
/show <info>View the modelfile, license, or system prompt.
/load <model>Swap out the current model for another one.
/save <name>Save the current chat configuration as a new model.
/clearClear the conversation history.

General Help

ollama --helpView the global help menu.
ollama <command> --helpView specific help instructions for any individual command.

Git

git statusShow staged/unstaged/untracked changes. Run before any tool that auto-commits (e.g. ContentPilot).
git status -sbShort form with branch tracking info.
git diffShow unstaged changes.
git diff --stagedShow staged changes.
git log --oneline -nCompact commit history, last n commits.
git add <file>Stage a specific file (prefer over git add -A).
git commit -m "msg"Create a commit.
git pushPush commits to the tracked remote branch.
git remote -vList configured remotes and their URLs.
git clone <repo> <dest>Clone a repo — used to make disposable test copies (e.g. before running ContentPilot against a real target).
git initInitialize a new repo — used for scratch/throwaway test repos.
git commit --allow-empty -m "init"Create an initial empty commit in a fresh throwaway repo.
git stashShelve uncommitted changes temporarily.
