GAP — Review Summarizer

Module F: Building the Review Summarizer (Full Capstone)

Restores the original 2-hour Review Summarizer project, dropped to a single sentence in the Python adaptation: DB setup, fetching reviews, generating and storing summaries, regeneration, edge cases, and displaying results.

PostgreSQL SQLAlchemy FastAPI
  • Defining the schema (reviews, summaries) and running migrations with Alembic.
  • Building the API to fetch reviews, then a separate API to generate and store an LLM summary — separating fetch logic from generation logic (service/repository split).
  • Handling regeneration (re-summarize on demand) and edge cases: zero reviews, one review, stale summaries.
  • Serving the summary and review list with pagination, replacing the original's Tanstack Query layer with a plain polling or server-rendered equivalent.

GAP — User & Ticket Management

Module G: Ticket Management — CRUD, Sorting, Filtering, Pagination, XSS

The single largest section of the original course (~2 hours) — reduced to nothing in the Python adaptation. Covers full ticket CRUD plus the security lesson ("Preventing XSS Attacks") that a support-ticket app specifically needs, since replies render user-submitted text.

SQLAlchemy bleach / nh3 Pydantic
  • Receiving, listing, sorting, filtering, and paginating tickets via query parameters (offset or cursor-based).
  • Viewing ticket details, assigning, updating, and replying to tickets — with clean interface extraction between the API layer and the persistence layer.
  • Preventing stored XSS in ticket replies: sanitize on write with bleach/nh3, and rely on auto-escaping if any HTML is templated server-side.

Primary Learning Resources:

  • How to Implement Pagination, Sorting and Filtering with FastAPI
  • Protecting Your Web App from Stored XSS: Flask, FastAPI, Django, ExpressJS
  • A Practical Guide to FastAPI Security

Module H: AI Features — Classification, Auto-Resolve, Background Jobs

Original section (1 hour) had polishing replies, summarizing tickets, classifying tickets, background job processing, and auto-resolving common requests. Python adaptation kept only badges. This restores the build.

Celery Redis Structured Output
