Course Curriculum & Learning Modules

GAP 1 — RAG

Module A: Retrieval-Augmented Generation from Scratch

Build a RAG pipeline: chunk documents, embed them, store vectors, retrieve relevant context, and ground LLM answers in it — the single most-requested skill across your job leads.

LangChain Embeddings Vector Store
  • Loading and chunking documents (PDF, Markdown, CSV) with LangChain's document loaders.
  • Generating embeddings and storing them in a vector database (Chroma) for similarity search.
  • Wiring retrieval into a generation call so answers cite source context instead of hallucinating.

Primary Learning Resources:

  • langchain-ai/rag-from-scratch (official GitHub repo, step-by-step notebooks)
  • RAG — Official LangChain Python Docs
  • A Practical Guide to Building Local RAG Applications with LangChain
GAP 1 — Evals & Guardrails

Module B: LLM Evaluation Workflows & Guardrails

Move past "it looks right" — build repeatable evaluation datasets, score outputs, and enforce structural/safety guarantees on what a model returns.

Ragas DeepEval Guardrails AI
  • Building test datasets and comparing prompts/models with reproducible scoring.
  • Tracing LLM outputs and reading eval results as an observability signal, not a one-off check.
  • Adding guardrails (via Pydantic schemas or Guardrails AI's RAIL spec) that catch hallucinations and PII leaks before output reaches a user.

Primary Learning Resources:

  • Safe and Reliable AI via Guardrails — DeepLearning.AI (free, by GuardrailsAI's founder)
  • LLM Evaluation for Builders: Applied Course — Evidently AI (10 free Python tutorials)
  • guardrails-ai/guardrails (official GitHub repo)
GAP 2 — Open-Source Models

Module C: Running Open-Source Models Locally

The original course's "Building with Open Source Models" section (28 min, 8 lessons) — restored. Covers picking, calling, and self-hosting Hugging Face models via Ollama.

Hugging Face Ollama Local Inference
  • Why and when to use open-source vs. commercial models (cost, data privacy, latency).
  • Finding and calling Hugging Face models directly from Python.
  • Installing Ollama, pulling a GGUF model, and calling it locally via the ollama Python library or LangChain's Ollama wrapper.

Primary Learning Resources:

  • How To Run an Open-Source LLM on Your Personal Computer — freeCodeCamp
  • Tutorial: Hosting local LLMs using Ollama and the Hugging Face ecosystem (GitHub)
  • Learn Ollama in 15 Minutes — Run LLM Models Locally for Free (YouTube)
