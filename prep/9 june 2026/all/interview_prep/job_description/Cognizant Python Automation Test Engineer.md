Job description
Job Description:


We are seeking a skilled QA Automation Engineer with strong expertise in Python programming and the Robot Framework. In this role, you will build, scale, and maintain automated test suites from scratch. You will collaborate closely with developers and product teams in an Agile environment to ensure rapid, high-quality software delivery.


Key Responsibilities


Framework Development: Design and scale custom keyword-driven automation frameworks using Python and Robot Framework.
Script Generation: Develop reusable, clean, and maintainable automated test scripts for Web UI, REST APIs, and backend systems.
Test Execution: Conduct functional, end-to-end, regression, and smoke testing across the application ecosystem.
CI/CD Integration: Integrate automated test suites directly into continuous execution pipelines using tools like Jenkins or GitHub Actions.
Database Validation: Write and execute SQL queries to perform extract, transform, load (ETL) or database-level test verification.
Defect Tracking: Identify, log, track, and manage software bugs using Jira, collaborating with developers to achieve resolution.
Code Review: Participate in peer code reviews to maintain automation script standards and infrastructure efficiency.

Required Technical Skills


Languages: Advanced proficiency in Python.
Frameworks: Hands-on experience with Robot Framework and its core libraries (e.g., SeleniumLibrary, RequestsLibrary).
Web UI Testing: Experience using Selenium WebDriver or Playwright integrated with Python.
API Testing: Proven experience validating RESTful APIs and microservices.
Version Control: Mastery of Git command-line basics and platforms like GitHub or Bitbucket.
Operating Systems: Comfortable working in Linux/Unix environments for executing scripts.

Experience & Qualifications


Education: Bachelors degree in Computer Science, Software Engineering, or a related technical discipline.
Experience: 3 to 6 years of specialized experience in software automation testing.
Methodology: Deep understanding of software testing life cycle (STLC) and Agile/Scrum processes.
Soft Skills: Exceptional problem-solving abilities and strong verbal and written communication skills.

Preferred (Good-to-Have) Skills

Experience with PyTest as an alternative Python testing tool.
Exposure to embedded system validation or IoT device testing using Robot Framework.
Knowledge of mobile automation via Appium.

Location- Chennai/Bengaluru/Coimbatore/Pune/Hyderabad
