## FASTAPI
- async = awaitable I/O on event loop; sync = threadpool auto-offload
- ⚠️ blocking trap: sync DB call inside async route starves the loop
- `Depends` = DI (Dependency Injection — lifecycle, testable, composable) — not just auth
- `response_model` = security boundary (hides internal fields from wire)
- Pydantic input → 422 auto. Pydantic output → strip extras.
- Gunicorn workers = multiple processes; each runs uvicorn loop
- CORS: explicit origins list — never wildcard in prod
- Scale: stateless → horizontal; Redis for shared state

## AUTH
- JWT = signed NOT encrypted → payload visible in DevTools ⚠️
- Access token ~15min / refresh token long-lived / Redis blacklist = revoke
- AuthN = who are you / AuthZ = what can you do (I built attribute RBAC)
- OWASP (Open Web Application Security Project) #1 = BOLA (Broken Object Level Authorization) → auth ✓ but missed ownership check per resource 💀
- bcrypt passwords. Never store plaintext. Never log tokens.
- OAuth2 = delegated auth; OIDC adds identity layer on top

## SQL — HIGH RISK ⚠️
- Execution order: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER → LIMIT
- INNER = matched rows only; LEFT = all left + NULLs for no match
- No-orders: `LEFT JOIN orders WHERE orders.id IS NULL`
- Nth per group: `DENSE_RANK() OVER (PARTITION BY x ORDER BY y DESC)` filter = N
- Duplicates: `GROUP BY col HAVING COUNT(*) > 1`
- COUNT(col) skips NULLs; COUNT(*) counts all rows — different answers
- ⚠️ Index trap: `WHERE LOWER(email) = ...` defeats index on `email`
- Index = fast read / slow write / not always used by planner
- EXPLAIN ANALYZE → Seq Scan = missing or unused index 💀
- Parameterized queries = no injection. Always.

## DECISION ONE-LINERS
- gRPC not REST (internal) → typed, fast, HTTP/2, no browser needed
- Redis not in-memory → shared across workers, survives restarts
- SQLite not Postgres (NFTRACE) → local, modest volume, zero-config
- Vector DB not keyword rules → same error, different wording = semantic match
- Celery not inline → slow work off the request, API stays responsive
- Regex fallback → AI can fail; 100% uptime via graceful degradation
- Attribute RBAC not role-only → fine-grained ownership per resource
